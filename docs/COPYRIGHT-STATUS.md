# Situação das fontes

O catálogo factual foi extraído do repositório público oficial de documentação Kali.
A raiz consultada continha README.md e _index.md, mas não LICENSE/COPYING.
A API GitLab informou license=null. A política geral de software Kali não é tomada
como autorização automática para copiar integralmente todo site, livro ou manual vinculado.

Por isso, o corpus de análise não acompanha o repositório publicável. Este contém
metadados factuais, URLs e textos autorais. O espelhamento/tradução integral aguarda
identificação de uma licença aplicável ou autorização específica das fontes.

Isso não declara que o conteúdo seja proibido; registra que a permissão de
redistribuição integral ainda não foi confirmada.

O snapshot de análise e seus hashes ficam fora do projeto. Não é anunciado como
documentação integral traduzida ou como release público finalizado.
