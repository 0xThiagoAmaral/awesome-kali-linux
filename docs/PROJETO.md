# Contrato do projeto

Nome: Awesome Kali Linux. Idioma principal: português. Formato: lista curada mais vault offline.
A documentação principal deve manter seções, conceitos, tabelas e exemplos das fontes autorizadas;
a cheatsheet é um complemento e não substitui o manual. Não fazer uma edição inglesa primeiro.
Fontes originais servem para procedência e comparação. Tradução automática exige sinalização e revisão.
Não traduzir silenciosamente flags, identificadores, código ou saídas literais.

Metas independentes: índice do catálogo; páginas oficiais preservadas sob permissão verificável;
tradução portuguesa completa; cheatsheets; revisão; testes; pacote offline; publicação.
Nenhuma meta é marcada concluída apenas porque diretórios ou links foram gerados.
