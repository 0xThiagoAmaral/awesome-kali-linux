# Configuração recomendada do Obsidian

Abrir a subpasta `vault`, não uma coleção de arquivos importados um a um.

1. Files and links: desativar Use Wikilinks para gerar links Markdown.
2. New link format: Relative path to file. Ativar atualização automática de links ao renomear.
3. Attachments: usar `99-Assets`, mantendo assets vinculados localmente.
4. Core plugins: habilitar Search, Backlinks, Outgoing links, Outline, Bookmarks e Templates conforme necessário.
5. Templates: selecionar `90-Templates`. Editar templates em modo Source e manter variáveis entre aspas.
6. Para aparência opcional, habilitar o snippet `fieldbook` em Appearance > CSS snippets.
7. Fixar `00-Home` e mapas favoritos. Usar propriedades para filtrar notas e backlinks para conceitos.

Não são fornecidos workspaces, credenciais, sincronização, plugins comunitários ou configurações pessoais.
Os menus podem variar conforme versão/idioma do Obsidian; as opções têm equivalência nas configurações.

Referências: [Links](https://obsidian.md/help/links), [Settings](https://obsidian.md/help/settings),
[Properties](https://obsidian.md/help/properties), [Templates](https://obsidian.md/help/plugins/templates).
